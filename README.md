# Ibiti Digital Map

Guia de navegação do Parque Ibiti Reserva. A aplicação permite localizar unidades e áreas comuns e abrir a coordenada correspondente em um aplicativo de GPS.

## Executar localmente

```bash
npm install
npm run dev
```

## Verificações

```bash
npm test
npm run build
```

## Situação dos dados

- Todas as unidades previstas estão disponíveis na busca.
- As 17 áreas comuns possuem coordenadas.
- As coordenadas residenciais serão complementadas progressivamente em `locations.json`.
